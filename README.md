# Lista 4 - Machine Learning

Este repositorio contiene la solución a la cuarta lista de ejercicios. 

## Estructura
- `data/`: Contiene los archivos CSV usados en los experimentos.
- `src/lista4/`: Módulo local con el código reutilizable para la carga de datos, modelos y cálculo de riesgos.
- `notebooks/`: Cuadernos con la ejecución de los experimentos y sus respuestas.

## Instalación y Ejecución
1. Instala las dependencias: `python -m pip install -r requirements.txt`
2. Instala el paquete local en modo editable: `pip install -e .`
3. Ejecuta Jupyter para correr los cuadernos ubicados en la carpeta `notebooks/`.
